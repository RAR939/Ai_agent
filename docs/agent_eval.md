# Оценка качества агента (Роль 5)

## Метрики
- **Tool Accuracy**: доля верно выбранных инструментов (из `eval/gold_agent.jsonl`).
- **Parameter Accuracy**: доля верно извлеченных параметров (например, правильная дисциплина).
- **Answer Accuracy**: доля правильных финальных ответов.
- **Среднее число шагов**: сколько шагов делает агент в среднем.
- **Среднее время ответа**.
