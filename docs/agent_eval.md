# Оценка качества агента (Роль 5)

## Метрики
- **Tool Accuracy**: доля верно выбранных инструментов (из `eval/gold_agent.jsonl`).
- **Parameter Accuracy**: доля верно извлеченных параметров (например, правильная дисциплина).
- **Answer Accuracy**: доля правильных финальных ответов.
- **Среднее число шагов**: сколько шагов делает агент в среднем.
- **Среднее время ответа**.

## Запасной режим (Rules)
Включается в `config.yaml` параметром `agent.mode: "rules"`.
Классификатор по ключевым словам описан в `config.agent.routing_rules`.

## Версии промпта
Агент работает с промптом `agent.prompt_version` (сейчас `agent_v2`: подстановка даты, таблица «вопрос → инструмент», правила источников). Версия пишется в `logs/agent_trace.jsonl`; для честного сравнения прогоните `eval/gold_agent.jsonl` на `agent_v1` и `agent_v2` и впишите оба столбца. Скрипта прогона пока нет (`docs/known_issues.md`).
